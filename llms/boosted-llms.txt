# Boosted.ai

> Boosted.ai is an agentic AI platform purpose-built for financial services and investment management. Its Alfa product delivers conversational financial chat and autonomous investment agents that automate research, market monitoring, idea generation, and reporting over verified, financial-grade data — exposed to developers via API, SDK, and embeddable UI.

## API

- [Boosted.ai API (Alfa)](https://www.boosted.ai/api): Investing Assistant, Insights Feed, and custom agent creation via API/SDK/embedded UI. Base URL https://alfa.boosted.ai/client. Auth: API key in the x-api-key header. Documented operation: POST /v2/workplans/{workplan_id}/run-workplan (execute a workplan to generate a research report).
